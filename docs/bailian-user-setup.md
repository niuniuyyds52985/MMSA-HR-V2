# 使用自己的百炼账户

真才实鉴使用者自行开通阿里云百炼、获取 API Key 并承担实际调用费用。项目不提供公共密钥、代付额度或充值服务。输入一次密钥后，模型名称和服务地址由程序配置，不需要在千问聊天中粘贴密钥。

## 获取密钥

1. 打开[阿里云百炼控制台](https://bailian.console.aliyun.com/)，登录自己的阿里云账户，按控制台提示开通模型服务。
2. 选择 **华北2（北京）**，按[官方 API Key 获取说明](https://help.aliyun.com/zh/model-studio/get-api-key/)创建普通按量模型 API Key。密钥与服务地域需要匹配。
3. 确认该密钥所在业务空间允许使用下表的两个模型，并自行管理账户额度与费用。
4. 回到真才实鉴弹出的本机密码框，粘贴密钥并保存。它只保存在当前 Windows 用户的加密配置中。

此处配置的是项目后台调用百炼所需的密钥。不要把千问办公的对话订阅、Token Plan 或 Coding Plan 的专用密钥代替本项目普通按量 API Key；不要发给项目开发者或粘贴到千问聊天。

## 本项目固定使用的模型

| 用途 | 固定模型 ID | 使用方式 |
|---|---|---|
| 三道问答的证据分析、八因子问答评级草稿和报告文字 | `qwen3.7-plus` | 按项目题库锚点、原话证据和固定提示词调用；本地程序完成加权计算 |
| 本地转写不可用时的云端音轨转写 | `qwen3-asr-flash` | 仅发送需要转写的音轨，不发送视频画面 |

模型名称在代码中统一固定。输入其他模型名或非允许的服务地址时，程序会拒绝请求；不会悄悄改用其他模型、把缺失评分补成成功，或将云调用失败伪装成本地规则评分。

面部点位、OpenFace AU、声音情绪模型仍在本机运行。这些本地模型属于既有多模态算法，不需要额外的百炼模型选择。

模型能力和调用方式可查看[千问文本模型说明](https://help.aliyun.com/en/model-studio/text-generation-model/)与[Qwen-ASR 接口说明](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)。实际费用、可用额度和账单以[百炼官方计费说明](https://help.aliyun.com/en/model-studio/model-pricing)及自己的控制台为准，本项目不承诺免费额度或固定单场费用。

## 配置或调用失败

保存密钥成功只表示已在本机配置，不表示账户权限、余额和云服务已实际验证。初始化本身不发送收费试评分。后续有真实回答需要分析时，若模型不可用、权限不足、额度不足或网络失败，原作答保留，报告标明相应缺项和失败原因。解决账户问题后再重试失败步骤。

需要重新输入密钥时，运行项目根目录的“配置百炼API.cmd”。不要编辑加密文件，也不要把旧电脑的加密配置复制给别人。
