# 真才实鉴交付与迁移

此交付面向模拟测试／方法验证。网页工作台、后台队列、百炼内容评价和独立研究运行复用同一数据库。旧版 Suit 情绪演示不属于本包启动入口。

2026-10-27 当前入口采用 **v4 面试流程**，新会话冻结 `interview.v4` 配置。创建时可选 `quick`（3 道主问、最多 1 道追问）或 `full`（8 道主问、最多 4 道追问，每主问最多追问一次）。两种模式从原题库按因子覆盖计划组卷；完整模式每因子一题，短体验只形成局部结论，不等于八因子完整评估。候选人检查一次设备，明确点击开始面试，结束每题后自动准备下一题；老师从工作台查看同场报告。默认自动分析为 OpenFace AU、OpenFace 视线、基础表情和声音四模块；Gaze360、EMOTIC 和原 AU-Net 保留为按需研究选项。旧会话保留原冻结配置、历史决策和报告，不因升级或打开页面补跑。当前设计见 [核心收敛与全题库方案](../docs/focused-report-question-bank-20261027.md)，[v3 业务流程](../docs/interview-v3-business-redesign.md)为历史基线。

历史验证记录：2026-10-26，Gaze360 与 EMOTIC 已完成 CPU、采集框回放、报告发布与备份恢复验证；公共 23.333 秒样片中分别为 23/24 有效窗（末窗缺未来帧）和 24/24。这些是工程样例记录，不是中文面试域准确率，也不表示它们仍默认运行。模型来源、许可与前处理限制见 [接入验收](../docs/model-integration-20261026.md)。

## 新电脑安装

1. 准备 Windows x64、Python 3.12 x64、FFmpeg 和 ffprobe。FFmpeg 的目录须在 PATH。CPU 推理可用；模型下载需要网络。
2. 解压源包，保持 `suit-demo/` 与根目录文档的相对结构。进入包根目录，运行 `suit-demo/setup-delivery.ps1 -DownloadModels -DownloadFastAsr`，安装 v4 默认基础模型与本地快速转写资产。脚本创建根目录 `.venv-suit`、安装固定版本依赖，不包含或调用百炼密钥。`-DownloadModels` 单独使用不会下载快速 ASR。需要独立研究时，另加可选参数 `-DownloadGaze360`、`-DownloadEmotic` 或 `-DownloadOriginalAuNet`；安装扩展权重不会把它们自动加入新场次默认分析。
3. OpenFace 使用其随包研究许可，下载脚本保留官方来源、版本、摘要和许可。分发/使用模型前依照对应许可，安装包不重新打包模型权重。视觉模型下载失败时保留真实失败状态；不要用合成值代替。
4. 运行 `.venv-suit/Scripts/python.exe suit-demo/delivery_tools.py doctor --verify-models` 查看依赖、FFmpeg 和固定资产摘要。字段 `optional_models` 列出原 AU-Net、Gaze360、EMOTIC，三者在 v4 均为非默认研究选项；未安装可选模型不表示默认四模块流程缺失。`fast_local_asr` 单独列出快速转写资产；缺失或失败时，实际转写可回退旧 Whisper base，并在结果记录回退来源。检查不联网或执行推理，资产齐全也不等于已完成新电脑运行验收。
5. 如需百炼内容分析，运行 `suit-demo/configure-interview.ps1`，在本机隐藏输入中配置 API Key。密钥由当前 Windows 账户的 DPAPI 保护，不写入文档、导入 JSON 或源包；新电脑/新账户需重新配置。
6. 运行`suit-demo/start-interview.ps1 -OpenBrowser`，或双击包根目录`启动面试工作台.cmd`（相对路径启动）。默认工作台地址`http://127.0.0.1:8766/workbench`；本机启动器负责安全打开凭证链接。
7. 常规合成验收：新建并选择短体验／完整八因子题组 → 检查一次设备并确认画面和声音 → 明确开始面试 → 每题“开始回答／结束回答” → 自动保存并准备追问或下一主问 → 按该场题量完成。短体验为 3 道主问、最多 1 道追问；完整题组为 8 道主问、最多 4 道追问。默认四模块在媒体保存完成后即调度，不等待转写或内容评分；本场作答结束不代表全部分析已完成。
8. 从工作台点击本场“查看报告”：先看潜力结论与八因子证据图，再看逐题原话、追问依据及少量同题声画观察；报告末尾逐项区分已体现、部分体现、明确不足、证据不足和本轮未测，并保留精确原话引用。点击观察可暂停定位实际采集点；原始数值、来源版本和完整观察折叠查看。逐题人工复核和高级研究保留在次级入口。纯文字回答没有音视频观察，缺失资产、无效采集窗或失败任务保留真实状态。
9. 独立方法对照另走高级研究页：明确选择素材／转写版本、模块、条件和重复次数 → 核对结果 → 按需显式发布研究附录。`au_net` 为可选原模型；`gaze360`、`emotic` 也可用于独立重复实验。独立实验的显式发布与默认四模块自动进入报告是两条不同路径；`semantic` 须另行授权文字云调用。新电脑必须完成自己的安装和运行验收，不能沿用本机结论。

`requirements-interview.txt` 记录本次独立工作台直接依赖；`requirements-local.lock.txt` 保留旧机器完整环境供溯源，其中还包含旧版 Suit 的额外依赖。环境不是通过复制现有 `.venv-suit` 来迁移。

## 老师如何查看报告与多模态

新 v4 场次直接打开整场报告，以内容证据和潜力模型结论为主，默认四模块的同题观察辅助回看；Gaze360／EMOTIC 只在显式研究运行并发布后出现在研究附录。声音描述给出相对本题有效发声窗口的音调／能量变化及基线；表情描述给出模型类别和同期实际 AU／点位。点击对应片段可查看原话、原片与真实采集点。同期 AU／点位是共现线索，不是分类器作出判断的因果解释。“低沉”“激昂”等复合听感尚无独立标注验证，不能把音高或能量变化包装成已验证的此类识别。

按需研究中的 Gaze360 显示 8 Hz 七帧输入的视线方向与角度区间，保留请求时间、实际帧时间及误差；EMOTIC 显示“场景辅助的感知情绪标签（研究）”四类 Anger、Happiness、Sadness、Surprise 的原始线性分值、对应验证阈值及缺失窗，不输出其余 22 类或 VAD，不把分值称为概率或情绪强度。点击采集点暂停定位原片：Gaze360 为实际头部输入框，EMOTIC 为人物裁剪框和完整场景框，只在对应原生帧时间绘制。它们不加入内容分、潜力图计算或自动选题。

旧场次按原冻结配置运行，包括历史 v3 已冻结的六模块计划；不会随 v4 默认配置被重写。新旧场次如需补做两模型，可进入本场高级研究显式选择回答和模块，核对后发布研究附录。研究发布生成新的报告版本，保留旧版本与内容分，不把后来的结果写成面试当时已有的证据。

两模块面向单人场景，多脸／多人窗口标记无效，不是多人面试或身份跟踪。Gaze360使用YuNet头部框，EMOTIC使用MobileNet-SSD人物框，与上游AlphaPose／YOLOv3前处理有差异。2026-10-26 接入记录中的 Gaze360 官方权重端点返回 403，Tandon EMOTIC 原发布目录返回 404；当前下载器使用固定提交中的社区保留权重并核对大小、Git blob和SHA-256，没有作者校验值可独立确认与原文件一致。详细来源、实际框坐标／时间及许可限制见[接入记录](../docs/model-integration-20261026.md)。

## 连续作答

中文目录启动兼容 Windows PowerShell 5.1 和 PowerShell 7：启动／停止脚本显式按 UTF-8 读取进程记录。若使用旧交付包遇到 `ConvertFrom-Json: Unrecognized escape sequence`，请更新这两个脚本；不需要删除面试数据或重新配置密钥。

本场只需在开始时检查一次设备，五秒试录可选；正常答下一题复用当前连接。等待期间未录制，可主动关闭设备，结束整场或离开页面会释放设备。同场新题沿用用户选择的音视频或文字方式。

新 v4 场次保存成功后由页面自动推进，不需要再按“继续”。本题无合法追问分支、追问预算已用完或已回答补充追问时，不等待内容评分；需要追问核对的主问，在取得文字后给予短语义核对最多 6 秒的决策窗口，逾时或失败即采用本地规则并记录回退。文字尚未取得时保留单独的转写等待上限；不能把 6 秒理解为每题全部处理的总耗时承诺。等待页说明正在准备下一题，异常时提供重试连接，刷新已保存题也会恢复推进，不自动开始录制下一题。旧配置按原政策运行。设备复用历史见[修复记录](../docs/candidate-flow-fix-20261026.md)。

v4 追问由词典线索和受限语义核对配合：短路由模型核对本题原话、词典命中和缺口，只能选择当前父题允许的原题库分支；条件不适用或证据无法核验时不据此追问。及时有效的结果标明模型实际参与，超时／失败则标明本地规则回退。词频高低、未命中和声画观察不直接换算能力分。完整内容评价在独立后台队列继续，报告区分当时封存的追问依据与后来模型意见，保留处理中、未测和失败状态；不倒写历史决定，也不展示模型内部思维链。

内容评分由两个 worker 共享队列并发处理，短路由使用独立队列；候选人不等待完整评分，老师可先读已经就绪的部分。以下为历史性能记录，不能用作 v4 耗时承诺：2026-10-26 隔离实测三题评分均成功：当时串行总计约 157 秒，首题约 77 秒含两次尝试，其余约 37／38 秒。新增并发调度旨在减少队列积压，并未消除供应商单次时延；重试可能更久，这组成绩不能外推为所有场次耗时或并发后的承诺。报告的“观察处理中”表示排队／运行；“观察缺失／失败”也包含已结束但有缺失窗口的部分结果，例如 Gaze360 末窗缺未来帧，不表示继续等待就会自动补齐。

## 源发布包

运行 `delivery_tools.py build`，在项目根目录 `delivery/` 创建带 UTC 时间标记的 ZIP、SHA-256 文件及文件清单。打包采用固定白名单，不扫描打包任意项目文件。内容包括工作台代码、配置、前端、测试、文档、启动/配置脚本和模型许可证/来源元数据。

源包排除 `.secrets-user`、`.token-secret`、数据库、原始媒体、个人会话导出、运行日志、下载临时文件、模型权重、Python 环境和本机 MCP 导入配置。解压后重新运行 `qwenwork/prepare-qwenwork.py` 生成当前路径的配置。

## 数据备份与恢复

`delivery_tools.py backup`用SQLite一致性快照生成私有备份包，并加入该快照引用的原片、已确认未完成上传片及规范路径下的观测JSON artifact，核对内容和摘要。旧artifact缺失会明确记入清单，不能声称文件完整。它不修改源库，可以在线备份；不包含预览缓存、临时文件或任意未被引用的文件。备份**含参与者回答、评分、报告与音视频**，不能当公开源包分享；不包含百炼API Key、operator凭据和会话token secret。

备份副本会清空 `operations` 幂等响应缓存，清除旧版缓存中的访问链接及创建恢复键，并清理 SQLite 空闲页；正式会话、回答、报告和决策记录仍保留。清理范围和数量记录在备份清单中。此处的凭据排除指系统管理的访问凭据，不会扫描或改写参与者自行输入的原文。

恢复示例：

```powershell
& '.\.venv-suit\Scripts\python.exe' '.\suit-demo\delivery_tools.py' restore --archive 'D:\备份\interview-backup.zip' --target 'D:\新项目\suit-demo\interview-data'
```

目标目录必须不存在；工具拒绝覆盖已有工作库。恢复会校验归档路径、文件摘要与数据库完整性，重定位原始媒体路径，生成新会话访问密钥并更新权限摘要。恢复也会清空幂等响应缓存，兼容尚未清理缓存的旧备份，避免重放旧访问链接。因此旧面试链接和旧操作重试缓存不再使用，须用新电脑工作台打开已有会话；勿用旧创建请求重建已有会话。未完成分析任务不会自动恢复执行；如需重新运行，应在新工作台显式操作。百炼与 operator 凭据在新账户重新配置。

旧数据如果仍需保留，先停止目标工作台，并在确认绝对路径后把旧数据目录独立保存，再恢复到新目录。工具不提供“覆盖”开关，也不会删除原数据库。恢复副本默认本地分析计划标为暂停，须由老师显式启用本场；原片可回放，跨机继续未完成上传仍需原录制文件，浏览器IndexedDB不随服务端备份迁移。合成恢复及隔离HTTP样片库在线恢复已验证，未对正式参与者库执行恢复。

2026-10-26 两模型整链路验证已核对报告历史、内容分保持不变及9个观测artifact完整迁移，其中包含规范路径`gaze360/gaze360-{run_id}.json`与`emotic/emotic-{run_id}.json`。这不触发产线既有会话重分析；验证记录见`local-data/interview-validation/model-integration-current.json`。

## 千问办公

详见 [千问办公接入说明](qwenwork/README.md)。已提供本地 STDIO MCP、导入配置生成器和技能 ZIP，复用同场进度与报告。MCP 创建会话支持 `form_mode="quick"` 或 `form_mode="full"`，省略时使用 quick，与网页和 API 使用同一组卷与封存规则。迁移后用目标项目的 Python 重新运行 `suit-demo/qwenwork/prepare-qwenwork.py`，生成本机路径；不要复制旧电脑的导入 JSON。连接器只提供限定业务工具，读取的报告进入千问办公对话并受该客户端数据设置约束。**千问办公桌面客户端实际导入、工具调用与同场报告联调仍未验收**；本地协议测试不能替代这一项。
