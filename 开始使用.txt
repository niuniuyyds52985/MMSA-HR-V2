真才实鉴 V2 · 给第一次使用的人

1. 完整解压安装包，在千问办公中选择这个解压目录。

2. 把下面一句话发给千问：

请读取当前项目的 QWEN_HANDOFF.md，完成真才实鉴初始化并打开 HR 总控。百炼密钥由我在本机密码框输入。

千问会运行固定初始化脚本，准备环境和模型。首次下载可能较久。
需要你操作时，只在本机密码框填写自己的百炼 API Key。
模型已经固定为 qwen3.7-plus（文本评分）和 qwen3-asr-flash（需要时的云转写），无需选择其他模型。
账户开通、余额及调用费用由你自己的百炼账户承担；我们不提供共享密钥或额度。

如果千问没有本机执行权限，只需双击“开始使用真才实鉴.cmd”，走同一个流程。

完成后会打开 HR 总控：新建批次 → 导入自己的 DOCX 简历 → 建立本机面试 → 查看个人报告与排名。
不用先找 Skill ZIP 或手动粘贴 JSON 才能打开总控。

百炼密钥获取和模型说明：docs\bailian-user-setup.md
后续日常使用：让千问打开 HR 总控，或双击“启动面试工作台.cmd”。
