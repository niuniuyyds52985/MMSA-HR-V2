# MMSA-HR V2 · 真才实鉴

**面向管培生模拟面试的 Windows 本地工作台。** 导入 DOCX 简历，完成五道情境单选和三道问答，生成带证据来源的个人报告与批次汇总。

> **项目状态：本地演示版。** 当前开发机的 V2 自动化测试与安装自检通过；干净电脑首次安装、真实招聘效度和千问桌面端完整接入尚未验收。仅用于教学模拟、流程演示和人工复核，不应作为招聘录用或淘汰的自动依据。

English: MMSA-HR V2 (真才实鉴) is a Windows x64, local-first interview simulation workbench. It creates an eight-question interview and evidence-linked review reports. The project is a demo and research tool, not a validated hiring assessment.

## 快速开始

### 方式一：下载源码包

在 GitHub 页面点 **Code → Download ZIP**，完整解压到当前 Windows 用户可写的固定目录。不要直接在 ZIP 内运行，也不要放入 `Program Files`。

### 方式二：克隆仓库

```powershell
git clone https://github.com/niuniuyyds52985/MMSA-HR-V2.git
cd MMSA-HR-V2
```

### 初始化并打开工作台

双击项目根目录的 **开始使用真才实鉴.cmd**。首次初始化会检查或准备 Python 3.12 x64、固定版本依赖、媒体工具和本地模型，然后运行自检并打开 HR 总控。首次需要联网下载依赖与模型；声音情绪模型约 1.12 GB，具体耗时取决于网络。

首次一键初始化会引导配置**自己的**百炼 API Key，并在本机弹出密码框。密钥和调用费用由使用者的百炼账户承担。若取消密钥配置，已安装的环境会保留，但一键入口不会继续打开 HR 总控；之后可重新运行初始化入口再配置。不要把密钥发到聊天、Issue、Skill 配置或源码文件中。模型、地域和配置步骤见[百炼账户配置](docs/bailian-user-setup.md)。

没有千问办公也可以直接运行初始化脚本。首次准备完成后，日常双击 **启动面试工作台.cmd**。若千问办公可执行本机脚本，可在千问办公中选择项目目录，并让它读取 [`QWEN_HANDOFF.md`](QWEN_HANDOFF.md)；千问 Skill/MCP 的生成配置需要在宿主实际导入后才算接通。

更详细的安装与故障处理见[独立安装说明](docs/v2-local-install.md)。

## 面试流程

1. HR 新建批次并导入一份或多份 DOCX 简历。
2. 为候选人创建面试并打开同一电脑上的候选人页面。
3. 候选人完成五道情境单选和三道开放问答，可使用文字或本机录音录像作答。
4. HR 查看个人 HTML 报告、逐题证据、复核记录和批次进度，并导出报告。

题量、计分和证据检查由后端固定执行。自动生成的内容是评分草稿，教师仍需核对原话、简历事实和证据缺口。系统不把视频或面部表现转换为诚信、人格或岗位能力结论。

完整验收步骤与已知限制见[本机 V2 验收说明](docs/v2-local-check.md)。

## 数据、隐私与费用

| 内容 | 处理方式 |
|---|---|
| 简历、作答、面试媒体、报告与数据库 | 保存在本机项目数据目录 `suit-demo/local-data/v2/` |
| 摄像头视频、OpenFace 点位及本地声音情绪分析 | 在本机处理；不会作为视频上传至百炼 |
| 问答评分 | 需要百炼时发送作答文本给固定模型 `qwen3.7-plus` |
| 语音转写 | 本地转写为空且启用云端回退时，只发送待转写音轨给 `qwen3-asr-flash` |
| API 密钥 | 使用当前 Windows 用户加密，保存在本机；不随源码包提供 |
| 云端费用 | 由使用者自己的百炼账户承担；测试套件不会发起付费 API 调用 |

本项目是**本机应用**，服务绑定 `127.0.0.1`。学生页面和 HR 页面设计为在同一台电脑使用；不提供局域网、异地访问或公网托管。

源码仓库不包含候选人资料、面试录音录像、报告、运行数据库、密钥、Python 环境或模型权重。模型与工具在首次初始化时从固定来源下载并校验。`.gitignore` 排除本机配置和运行数据；提交前仍应自行确认没有加入私有资料。

## 系统要求

- Windows x64；首次安装需要网络与有写入权限的目录。
- 初始化脚本会准备项目专用 Python 环境和固定依赖；无需手工安装模型。
- 百炼账户和 API Key 只在需要云端评分或云端转写时使用。
- 摄像头、麦克风可选；也可以使用文字或已有媒体文件。

## 本机检查与开发

完成初始化后可运行只读环境自检：

```powershell
.\.venv-suit\Scripts\python.exe -B -X utf8 scripts\install_v2.py --doctor
```

运行 V2 自动化测试：

```powershell
.\.venv-suit\Scripts\python.exe -B -X utf8 -m unittest discover -s tests\v2 -q
```

2026-11-09 的当前开发机检查为 **215 项 V2 测试通过**，安装自检为 `ready`。这表示代码与这台电脑的运行环境通过检查，不等于已在另一台干净电脑、真实千问客户端或真实招聘场景验收。

`suit-demo/` 中保留 V2 调用的兼容模块、凭据适配、媒体处理和模型安装位置；其中的 V1 启动器与旧工作台说明只供历史兼容，不是 V2 的日常入口。

## 已知限制

- 干净 Windows 电脑首次下载、安装、摄像头/麦克风授权和模型推理尚未完成端到端验收。
- 千问办公真实导入 Skill/MCP、首次执行和工具调用尚未完成端到端验收；配置文件生成不代表已经安装。
- V2 人员数据的专用备份与恢复功能仍待补齐。源码包不是数据备份。
- 多模态五态映射是演示规则，尚无独立人工标注集验证其准确性或招聘测量效度。
- 云端评分和转写需要使用者自行配置网络、权限和额度；自动评分失败时应由老师核验并显式重试。
